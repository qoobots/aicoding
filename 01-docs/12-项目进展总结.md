## 3. API 接口清单

### 3.1 项目管理 API

| 方法   | 路径                        | 说明         |
| ------ | --------------------------- | ------------ |
| POST   | `/api/projects`             | 创建项目     |
| GET    | `/api/projects`             | 获取项目列表 |
| GET    | `/api/projects/:id`         | 获取项目详情 |
| PUT    | `/api/projects/:id`         | 更新项目     |
| DELETE | `/api/projects/:id`         | 删除项目     |
| PUT    | `/api/projects/:id/status`  | 更新项目状态 |
| PUT    | `/api/projects/:id/restore` | 恢复项目     |

### 3.2 模板管理 API

| 方法   | 路径                                | 说明         |
| ------ | ----------------------------------- | ------------ |

| GET    | `/api/templates/:id`                | 获取模板详情 |
| PUT    | `/api/templates/:id`                | 更新模板     |
| DELETE | `/api/templates/:id`                | 删除模板     |
| POST   | `/api/templates/render`             | 渲染模板     |
| GET    | `/api/templates/type/:type`         | 按类型查询   |

## 7. 已知问题和限制

### 7.1 技术债务

1. **测试覆盖率不足**: 当前仅有 Service 层单元测试,缺少 Controller 层和集成测试
2. **错误处理不完善**: 部分错误场景处理不够细致
3. **性能未优化**: 前端未做代码分割,后端查询未做优化

### 7.2 功能缺失

1. **用户认证系统**: 当前无用户认证和权限管理
2. **数据迁移**: 缺少数据库版本管理和迁移机制
3. **备份恢复**: 无数据备份和恢复功能
4. **日志系统**: 缺少统一的日志收集和分析

### 7.3 部署相关

1. **Electron 打包**: 未配置 Electron 应用打包
2. **Docker 支持**: 无 Docker 容器化配置
3. **CI/CD 流水线**: 基础配置存在但不完善
